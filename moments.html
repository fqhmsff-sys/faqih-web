Foto-foto lama yang tetap disimpan apa adanya. Bukan untuk menjadi galeri besar, hanya potongan kecil dari perjalanan.

MOMENTS / HOW TO ADD

Tambahkan foto baru.

Cara paling aman untuk website static ini: masukkan file foto ke folder images/, lalu tambahkan satu blok foto di moments.html.

01

Masukkan foto
Contoh: images/moment-03.jpg

02

Duplikasi satu figure
Salin blok foto yang sudah ada lalu ganti nama file, nomor, dan caption.

03

Save → GitHub
Push perubahan dari Acode. GitHub Pages akan menampilkan foto baru.

Kalau nanti jumlah Moments sudah banyak, struktur ini bisa diubah menjadi data-based gallery supaya lu cukup menambah data tanpa menyentuh layout.
